## 📖 نظرة عامة | Overview

«وِرد» تطبيق سطح مكتب صُمم خصيصًا لمن يعمل على حاسوبه المحمول أو المكتبي وينسى أوراده اليومية بمجرد انشغاله بالعمل وتدفق المهام. 

التطبيق ليس قارئًا للقرآن أو مستودعًا للنصوص، بل هو **أداة تذكير هادئة ومستقلة** تعمل في الخلفية بكفاءة عالية، تنبهك عند حلول وقت الورد، وتتيح لك جلسات تفرّغ هادئة لإنجاز أورادك، مع متابعة التقدم دون تشتيت أو شعور بالذنب، وتعمل بالكامل محليًا دون الحاجة إلى حساب أو إعلانات أو اشتراكات.

## ✨ المميزات الرئيسية | Key Features

- **المهام الافتراضية والمهام المخصصة**:
  - أذكار الصباح، أذكار المساء، والورد القرآني اليومي مع إمكانية إضافة مهام مخصصة غير محدودة (مثل قيام الليل، صلاة الضحى، سورة الكهف).
  - تحديد فترات البداية والنهاية، وفواصل التكرار، وأيام التكرار، والأهداف العددية الاختيارية (صفحات، ركعات، تكرار).
- **«جلسة تفرّغ» (Focus Session)**:
  - واجهة كاملة هادئة خالية من التشتيت مع عداد تنازلي دقيق محسوب بساعة الحائط.
  - إمكانية تثبيت النافذة فوق النوافذ الأخرى (`Always on Top`) دون سرقة التركيز من لوحة المفاتيح.
  - إيقاف مؤقت تلقائي عند قفل الشاشة أو سكون النظام (`Lock / Suspend`) دون احتساب وقت التوقف كوقت قراءة.
  - آلية حماية من الخروج الاندفاعي تتطلب الضغط المطول (Hold-to-exit) مع تأكيد صريح.
  - عند انتهاء الوقت، يسأل التطبيق بهدوء: «هل أتممت القراءة؟» مع خيارات للتمديد أو الإنهاء أو التأكيد دون فرض الإنجاز التلقائي.
  - استعادة تلقائية لحالة الجلسة في حال إعادة تشغيل الجهاز أو انقطاع التطبيق.
- **نافذة التذكير المصغّرة (Mini Reminder Window)**:
  - نافذة عائمة مصغّرة غير سارقة للتركيز (Non-focus-stealing) تظهر بهدوء فوق النوافذ إلى جانب إشعارات Windows.
  - تتيح البدء الفوري «هبدأ دلوقتي»، أو التأكيد «تمّت القراءة»، أو «التأجيل».
  - تحكم كامل بموضعها (أسفل اليمين، أسفل اليسار، أعلى اليمين، أعلى اليسار) مع توافق تام مع الشاشات المتعددة واختلاف الـ DPI وإعادة التموضع عند فصل الشاشات.
  - إغلاق النافذة لا يُسقط التذكير ولا يعتبره مكتملًا.
- **تأجيل ذكي وتحذير انتهاء الفترة**:
  - خيارات تأجيل سريعة (5، 15، 30 دقيقة).
  - تنبيه واضح وتلقائي إذا كان وقت التأجيل سيتجاوز نهاية فترة المهمة المحددة.
- **محرك جدولة حتمي واستقلال تام**:
  - معالجة دقيقة للفترات الزمنية العابرة لمنتصف الليل مع توليد معرّف دورة فريد (`occurrenceId`) لمنع التكرار أو فتح المهام المنجزة.
  - استمرار التذكيرات في الخلفية حتى بعد إغلاق نافذة التطبيق دون الاعتماد على بقاء واجهة React مفتوحة.
  - إعادة تقييم التذكيرات فور استيقاظ الجهاز من السكون أو فتح القفل دون إغراق المستخدم بتراكم الإشعارات المتأخرة.
- **تنسيق الأولويات والتنسيق المركزي**:
  - 1. جلسة التفرّغ النشطة (كتم التنبيهات الأخرى أثناء الجلسة).
  - 2. الإيقاف المؤقت بطلب المستخدم.
  - 3. التذكيرات المستحقة في مواعيدها.
  - 4. التحديثات والعمليات غير العاجلة.
- **هوية بصرية عربية هادئة**:
  - خط **Readex Pro** مدمج بالكامل محليًا للأحرف العربية والإنجليزية مع ترخيصه الرسمي (SIL OFL).
  - ارتفاع سطور مضبوط (`line-height`) يمنع قص الحركات والأحرف العربية.
  - احترام إعدادات تقليل الحركة (`prefers-reduced-motion`) ودعم التباين العالي وإمكانية الوصول.
- **تخزين محلي ذري ونسخ احتياطية متناوبة**:
  - حفظ البيانات في مجلد `userData` الخاص بنظام التشغيل.
  - كتابة ذرية (Atomic Write) لمنع تلف البيانات عند انقطاع التيار الكهربائي.
  - نظام نسخ احتياطية متناوبة تلقائي يحتفظ بأحدث 5 نسخ دورية في مجلد `backups/`.
  - تصدير واستيراد النسخ الاحتياطية بصيغة JSON مع فحص تطابق الـ Schema.
  - **خصوصية مطلقة**: لا يتضمن التطبيق أي تتبع (Analytics) أو جمع بيانات شخصية.
- **تحديث تلقائي عبر GitHub Releases**:
  - تكامل متين مع `electron-updater` للبحث الدوري واليدوي عن التحديثات وتنزيلها وتطبيقها بنقرة زر.

## 🛠 التقنيات المستخدمة | Tech Stack

- **Electron**: منصة سطح المكتب الحديثة (الإصدار 33+).
- **React 18 + TypeScript**: واجهة مستخدم سريعة ومكتوبة الأنواع بدقة.
- **electron-vite & Vite 5**: أداة بناء وتطوير فائقة السرعة للمراحل الثلاث (Main, Preload, Renderer).
- **Tailwind CSS**: تصميم عصري متوافق مع Windows 11 ومبادئ التصميم الهادئ.
- **Readex Pro**: خط عربي ولاتيني مدمج محليًا برخصة SIL OFL.
- **electron-builder**: لبناء حزم التثبيت NSIS لنظام Windows.
- **electron-updater**: لتنزيل التحديثات بأمان من GitHub Releases.
- **Vitest**: بيئة اختبارات مؤتمتة لمنطق الجدولة والجلسات والترقيات والتخزين (35 اختبارًا مؤتمتًا).

## 🚀 البدء والتشغيل محليًا | Getting Started

### 1. المتطلبات المسبقة
- تثبيت [Node.js](https://nodejs.org/) (إصدار 20 LTS أو أحدث).
- تثبيت [pnpm](https://pnpm.io/) (`npm install -g pnpm`).

### 2. تثبيت الحزم وإعداد المشروع
```bash
# استنساخ المستودع
git clone https://github.com/wird-app/wird.git
cd wird

# تثبيت الاعتماديات
pnpm install

# تنزيل وفحص ثنائيات Electron
node ./node_modules/electron/install.js
```

### 3. أوامر التطوير والفحص
```bash
# تشغيل التطبيق في وضع التطوير (Hot Module Replacement)
pnpm dev

# تشغيل اختبارات الوحدة المؤتمتة (Vitest)
pnpm test

# فحص صحة الأنواع البرمجية (TypeScript Typecheck)
pnpm run typecheck

# بناء ملفات الإنتاج (Production Build)
pnpm run build

# حزم مثبت Windows (NSIS Installer) محليًا
pnpm run dist
```

## 🔄 التحديث التلقائي وسير العمل عبر GitHub Releases | Auto-Updates

يستخدم التطبيق مكتبة `electron-updater` بالاتصال مع مستودع GitHub العام:

### آلية عمل التحديثات:
1. **البحث التلقائي واليدوي**: يتحقق التطبيق بعد 15 ثانية من التشغيل، ثم دوريًا كل 4 ساعات، أو يدويًا من شاشة الإعدادات أو علبة النظام.
2. **المستودع العام**: قراءة بيانات الإصدارات لا تتطلب أي توكن أو سر مضمن في التطبيق.
3. **التنزيل الآمن**: يتم تنزيل حزمة التحديث والمقارنة عبر ملف `latest.yml` وبصمات الـ hash (Blockmap).
4. **التطبيق الآمن**: يُعرض للمستخدم خيار «إعادة التشغيل والتثبيت» في الوقت الذي يناسبه، مع حفظ حالة البيانات بالكامل قبل الخروج.

### متطلبات التوقيع الرقمي لنظام Windows (Authenticode Signing):
لبناء نسخة موقعة رقميًا في سير عمل GitHub Actions، يلزم ضبط الأسرار التالية في إعدادات المستودع (**Settings > Secrets and variables > Actions**):
- `WIN_CSC_LINK`: رابط مشفر أو ملف بصيغة Base64 لشهادة توقيع البرمجيات (`.pfx`).
- `WIN_CSC_KEY_PASSWORD`: كلمة مرور الشهادة.

> [!NOTE]
> عند عدم توفر شهادة مدفوعة، يمكن بناء التطبيق كنسخة غير موقعة (Unsigned). سيعرض Windows رسالة فحص SmartScreen المعتادة للملفات المحملة لأول مرة حتى يكتسب الملف سمعة وثقة (Reputation).

## 🛡️ الأمان والخصوصية | Security & Privacy

- **Context Isolation**: معزول بالكامل لمنع أي تداخل بين واجهة الويب ونظام التشغيل.
- **Node Integration**: معطل في الواجهة (`nodeIntegration: false`).
- **No External CDN**: جميع الخطوط (Readex Pro) والأيقونات والأصول مدمجة محليًا بالكامل.
- **Safe External Navigation**: تفتح جميع الروابط الخارجية في متصفح النظام الافتراضي بعد التحقق من عنوانها.
- **Offline First**: تخزين محلي كامل في `userData` مع 0 تتبع و0 استعلامات خارجية باستثناء التحديثات.
